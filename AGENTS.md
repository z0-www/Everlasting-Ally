# Development

Run `npm ci`, `npm run build`, and `npm test`. The package is a local TypeScript library and uses Node 24's built-in `node:sqlite`; no model API key is required.

Continuity is disabled by default. Never treat proposed changes as active until an explicit user approval operation is performed. Keep scope identifiers supplied by trusted host identity; this package's service is deliberately single-process and does not claim multi-user authentication.
